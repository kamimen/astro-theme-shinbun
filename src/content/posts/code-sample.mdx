## 写真を入れる

Markdown の `![]()` で書いた画像は、自動で最適化されます。MDX なら、`Image` の部品も使えます。

<Image src={river} alt="夜の川沿い（ダミー画像）" width={900} height={600} />

## コードを入れる

```ts
export function isPublished(post: PostLike): boolean {
  return !post.data.draft;
}
```

昼と夜の紙面で、コードの色も切り替わります。
